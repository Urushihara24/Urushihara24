- **Risk-based testing:** focus effort on revenue, access control, state transitions and integration failure modes.

## How I investigate failures

```text
Understand the product and business risk
                    ↓
Model critical paths and state transitions
                    ↓
Reproduce and isolate the failing layer
                    ↓
Collect UI, API, database and log evidence
                    ↓
Explain impact, likely cause and release risk
```

I value test documentation that helps a team make decisions—not documentation created for its own sake. The repositories above contain the underlying cases, defect registers, evidence and investigation notes.
